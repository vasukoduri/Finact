# Security policy

## Reporting a vulnerability in finact

Please **do not open a public issue** for security problems in finact itself. Use GitHub's private vulnerability reporting (Security → Report a vulnerability). You should get an acknowledgement within 7 days.

## Responsible use

finact is meant for testing agents you own or are authorized to assess, against its sandbox bank or a staging environment with synthetic data. It never needs real money, real accounts or real customer data. If it reveals that a production agent can move funds without authorization, follow your organization's incident-response and disclosure procedures.
